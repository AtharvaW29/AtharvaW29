## 🚀 Featured Projects

### 🚁 ARES: UAV Navigation Under Sensor Failure
> *MATLAB · Simulink · PyTorch · SAITS · BarrierNet · ONNX*

Research project on single-UAV navigation when LiDAR is intermittent or unavailable. Combines a MATLAB/Simulink quadrotor simulation, reproducible telemetry and dataset collection, and Python training of reconstruction models (SAITS, CNN/MLP, sparsity-invariant CNN) that supply estimated observations during sensor outages. Includes a state-augmented SAITS reconstructor trained with a differentiable barrier QP, and native MATLAB inference checked against PyTorch reference cases.

[![Repo](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github)](https://github.com/awagh29/ARES)

---

### 🗄️ NothingDB: Relational Database Engine in Modern C++
> *C++20 · CMake · Storage Engines · Query Processing · Systems Programming*

A relational database management system built from scratch with a modular CMake build. Implements page-based storage, tuple lifecycle management, logical deletion and RID-based updates, and explores buffer pool management, B+ tree indexing, query parsing and execution pipelines. Roadmap: transactions, write-ahead logging and concurrency control.

[![Repo](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github)](https://github.com/AtharvaW29/NothingDBFromScratch)

---

### 🔄 SYNC: Agentic Workflow Synchronization Layer
> *TypeScript · SpacetimeDB · Node.js · Vitest · Docker*

A framework-agnostic layer that coordinates finite worker, station and reusable-resource capacity through an authoritative SpacetimeDB execution engine. Ships a live dashboard, a primal-dual planner with a reproducible benchmark command, and real worker subprocesses with scale-up, execution and cancellation.
